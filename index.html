First-time setup
Step 1 — Connect Firebase
Firebase is Google's free real-time database. It lets all team members see live updates when tasks are assigned or updated. Free tier is more than enough for SEECA.
Quick setup (5 minutes):
1 Go to console.firebase.google.com
2 Click "Add project" → name it seeca-team-management → Create
3 Click "Realtime Database" in left menu → "Create database" → Start in test mode
4 Click the ⚙️ gear → "Project settings" → scroll to "Your apps" → click </> (Web)
5 Register app → copy the firebaseConfig values below
Step 2 — Set manager password
This password protects the manager/CEO dashboard.
Step 3 — Set up EmailJS (optional)
EmailJS lets SEECA Team Management send real emails. 200 free emails/month.
✅ Setup complete!
SEECA Team Management is ready.
