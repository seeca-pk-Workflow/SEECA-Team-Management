First-time setup
Step 1 — Connect Firebase
Firebase is Google's free real-time database. It lets all team members see live updates when tasks are assigned or updated. Free tier is more than enough for SEECA.
Quick setup (5 minutes):
1 Go to console.firebase.google.com
2 Click "Add project" → name it seeca-agent → Create
3 Click "Realtime Database" in left menu → "Create database" → Start in test mode
4 Click the ⚙️ gear → "Project settings" → scroll to "Your apps" → click </> (Web)
5 Register app → copy the firebaseConfig values below
Step 2 — Set manager password
This password protects the manager/CEO dashboard. Team members use their own PIN.
Step 3 — Set up EmailJS (optional)
EmailJS lets SEECA Agent send real emails to team members when tasks are assigned or put on hold. 200 free emails/month — more than enough.
Setup: Go to emailjs.com → Free account → "Email Services" → connect Gmail → "Email Templates" → create template with variables: {{to_email}}, {{to_name}}, {{subject}}, {{message}}
✅ Setup complete!
SEECA Agent is ready. The manager dashboard is password-protected. Team members log in with their name and PIN. You can add team members from the Manager Panel.
